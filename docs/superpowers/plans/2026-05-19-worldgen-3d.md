# Worldgen 3D — Implementation Plan

> **Spec:** `docs/superpowers/specs/2026-05-19-worldgen-3d-design.md`
> **Tunables:** Defaults from the spec — `DENSITY_FALLOFF=4.0`,
> `RELIEF_AMP=1.0`, `RELIEF_PERIOD=32.0`, `SURFACE_BAND=8` (PR A) /
> unbounded (PR B).

**Goal:** Replace per-column "fill solid up to height" with a 3D
density evaluator. PR A ships surface-band 3D (kills the chevron-
staircase artifact). PR B widens to full 3D + soft cave SDFs.

---

## PR A — Surface-band 3D density

**Files modified:**
- `src/worldgen/tuning.rs` — add `DENSITY_FALLOFF`, `RELIEF_AMP`,
  `RELIEF_PERIOD`, `SURFACE_BAND`.
- `src/worldgen/heightmap.rs` — add `DensityNoise` struct with
  `evaluate(seed, h_target, wx, wy, wz) -> f32`.
- `src/worldgen/mod.rs::Generator` — new `density: DensityNoise`
  field, initialised in `new`.
- `src/worldgen/mod.rs::fill_chunk` — rewrite the inner per-voxel
  loop to top-down density scan; new `select_surface_block` /
  `select_subsurface_block` helpers.
- `src/worldgen/mod.rs::tree_in_cell` — find topmost solid via
  on-demand density walk (32 evals worst case).
- Re-baseline `golden_seed42_chunk_0_2_0` + map fingerprint.
- New tests: `density_is_pure`, `density_above_target_mostly_air`,
  `density_below_target_mostly_solid`.

## PR B — Unbounded 3D + soft cave SDFs

**Files modified:**
- `src/worldgen/tuning.rs` — bump `SURFACE_BAND` to a large value
  (`i32::MAX` effectively).
- `src/worldgen/caves.rs` — replace `cave_air` / `entrance_air`
  booleans with `cave_sdf` / `entrance_sdf` returning soft
  signed distances. Density subtracts these instead of overriding.
- Re-baseline goldens.

---

## Risks

- **Performance** — PR A: ~1.5× chunk gen. PR B: ~3×. Bench before
  merge; mitigation = tune `SURFACE_BAND` smaller if too slow.
- **Tree placement** — on-demand topmost-solid walk adds ~32 evals
  per tree cell. Should still be fast.
- **Cave surface buffer** — currently uses precise `depth = h - wy`.
  In 3D, depth is dynamic from the top-down scan. Use approximate
  `h_target - wy` for the buffer check.
- **`is_cliff`** — based on h_pre slope, still meaningful. Keep.
